Turn a spare Android phone into an AI you can reach by ordinary SMS, from any phone, with no mobile data.

Leave the relay phone at home on Wi-Fi. Text its number from anywhere SMS works (satellite texting, roaming without data, weak rural signal, a basic feature phone) and it texts back an answer from the AI provider you choose.

<b>Features</b>
<ul>
<li>Claude, Gemini, Gemma, OpenAI, Groq, Cerebras, Mistral or OpenRouter, using your own API key; several have free tiers</li>
<li>Remembers the conversation per sender; text /new or RESET to start over, and idle conversations reset automatically</li>
<li>Only replies to numbers on your allowlist; everyone else is ignored before any API call or SMS is spent</li>
<li>API keys encrypted with the Android Keystore</li>
<li>Everything stays on the relay phone: no server, no account, no analytics</li>
</ul>

<b>You need</b>
<ul>
<li>A second Android phone (8.0+) with its own SIM, kept charged and online</li>
<li>An API key from one of the supported providers (usage is billed by them)</li>
<li>An SMS plan on the relay SIM: every reply is sent from it, and long answers take several texts</li>
</ul>

This app was entirely generated by AI, from the code to the test cases. Only the testing on real phones was done by a human. Reviews and contributions from experienced Android developers are very welcome.
