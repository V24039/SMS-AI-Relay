# SMS AI Relay

Ask an AI questions by plain SMS, from any phone, with no mobile data. A spare Android
phone at home receives your text, asks the AI provider you chose using your own API key,
and texts the answer back.

> [!IMPORTANT]
> **This project was entirely generated by AI**, from the code to the test cases.
> The only part done by a human was testing the app on real phones. The maintainer is not
> an Android developer and can't fully review the code. Please read it before trusting
> it with your SMS and API keys, and see [Contributing](#contributing) if you can help.

```
Your phone (SMS only, no data)
   → ordinary SMS →
Relay phone (this app, on Wi-Fi or data)
   → Claude / Gemini / OpenAI / Groq / … with your own key
   → reply sent back by SMS
```

## When it's useful

- **Off-grid via satellite texting.** Newer phones and some carriers can send ordinary
  SMS over satellite. Text the relay from a trail or a boat and get an answer.
- **Roaming without a data plan**, where SMS is cheap or included.
- **Weak rural signal** where texts get through but data doesn't.
- **Basic feature phones**: set it up so a relative without a smartphone can ask
  questions by text.
- **Internet shutdowns**, if the relay phone is somewhere that still has internet.

## What you need

- **A second Android phone** (Android 8.0 or newer) with its **own SIM**, kept charged
  and connected to the internet. It stays at home as the relay.
- **An API key** from [Anthropic](https://console.anthropic.com/) (Claude),
  [Google AI Studio](https://aistudio.google.com/) (Gemini and Gemma) or
  [OpenAI](https://platform.openai.com/), which bill you for usage, or from a provider
  with a free tier: [Groq](https://console.groq.com/), [Cerebras](https://cloud.cerebras.ai/),
  [Mistral](https://console.mistral.ai/) or [OpenRouter](https://openrouter.ai/) (its free
  models). Free tiers have rate limits that change over time; check the provider's page.
- **An SMS plan on the relay SIM.** Every reply is sent from it, and a long answer is
  split into several texts. Some prepaid plans limit SMS per day (often around 100 in
  India), and carriers may flag heavy automated texting.

## Features

- Eight providers: Claude, Gemini, Gemma, OpenAI, Groq, Cerebras, Mistral and OpenRouter
  (its free router picks a currently free model for each request). Switch any time in
  Settings, with an optional model override.
- Conversation memory per sender, so follow-up questions work.
- Text `/new` or `RESET` to start a fresh conversation. Conversations also reset after
  45 idle minutes (configurable), and only recent history is sent to keep requests small.
- Long replies are sent a few messages at a time, with a short pause between them. Text
  `/stop` or `STOP` to cancel the rest (and any question still being answered), which
  saves SMS if your plan has a message limit.
- **Sender allowlist**: only numbers you add get a reply. Everyone else is ignored before
  any API call or SMS is spent. An empty list replies to nobody.
- API keys are encrypted with a key held in the Android Keystore.
- Runs as a foreground service with a quiet notification, and restarts after a reboot.
- **Private by design**: no server, no account, no analytics. Your key, settings and
  history stay on the relay phone and are excluded from cloud backup. The only network
  traffic is the request to the AI provider you picked.

## Install

**Not on the Google Play Store, and it won't be.** Play only allows the SMS permissions
this app needs for apps that are the phone's default SMS app, and this isn't one.

1. Download the latest APK from the [Releases](https://github.com/OWNER/sms-ai-relay/releases) page.
2. Open it on the relay phone and allow "install unknown apps" for your browser or file
   manager when asked.

Google has announced developer verification requirements for apps installed from outside
the Play Store, rolling out from 2026. Depending on your country and Android version,
installing may need extra steps. Check the current status if the install is blocked.

## Set up

1. Open the app and tap **Grant SMS Permissions**.
2. Tap **Turn Off Battery Optimization** and allow it. Without this, Android can cut the
   app's internet while the phone is idle and replies may be late or never arrive.
3. Open **Settings**: pick a provider, paste your API key, add your own phone number(s)
   to the allowed senders, and tap **Save**.
4. Text the relay's number from an allowed phone. You should get an answer within a
   few seconds.

**Samsung, Xiaomi, OnePlus, Huawei and others** add their own battery managers that can
still kill the app. See [dontkillmyapp.com](https://dontkillmyapp.com/) for your phone's
settings, and also allow the app to run in the background / autostart.

## Limitations

- Needs a second phone that's always on; this isn't something you run on your main phone.
- If Android kills the app mid-request, that message is lost; text again.
- Only the relay's owner is meant to use it: one API key, one allowlist, no per-user limits.
- Replies are plain text and kept short, since they arrive as SMS.

## Build from source

Requires JDK 17–21 (Gradle 8.7 doesn't run on JDK 22+). Android Studio works too, as long
as its Gradle JDK is set to 17–21.

```bash
./gradlew assembleDebug        # APK in app/build/outputs/apk/debug/
./gradlew testDebugUnitTest    # unit tests, including Robolectric tests of the Android parts
```

On Windows use `.\gradlew.bat`, and set `JAVA_HOME` to a JDK 17–21 first if your default
`java` is newer.

SMS behaviour has to be tested on a real phone with a SIM; the emulator can't send real
texts. Watch Logcat for the `SmsReceiver`, `RelayService` and `SmsRelay` tags.

[AGENTS.md](AGENTS.md) describes the architecture, design decisions and code layout.
[RELEASING.md](RELEASING.md) covers signing and publishing releases.

## Contributing

Help from people who know Android is especially welcome, because nobody has
reviewed this code yet. Useful contributions:

- **Code review**, especially of background execution, permissions and key storage.
- **Testing on different phones and Android versions**, and reporting what breaks.
- **Co-maintainers** who can review pull requests.
- More providers. OpenAI-compatible ones (Together, DeepSeek, …) only need a new
  `OpenAiClient` instance with a different base URL and a new `AiProvider` entry.

Please open an issue before large changes. CI runs the unit tests on every pull request,
and **new code needs tests**: a PR fails if under 80% of the app lines it adds or
changes are run by a test. The check's summary page lists the untested lines. Run
`./gradlew createDebugUnitTestCoverageReport` to see coverage locally.

This project deliberately has no server component. See AGENTS.md for the reasoning
before proposing one.
